# bomberCAT :)

joguinho inspirado em bomber-man mas numa pegada mais pique-pega, com gráficos
desenhados com base nos sprites antigos de OMORI. feito com amor para o projeto
de Linguagem de Programação II, e agora **rodando direto no navegador**, sem
precisar instalar nada.

esta é a versão web do [bomberCCAT](https://github.com/birenes/bomberCCAT): o mesmo
jogo em C/SDL2, compilado pra WebAssembly e empacotado num arquivo só.

*Requisitos:*
- 1 computador
- 1 navegador

isso mesmo, cabou o cmake e o sdl dando trabalho :)

## Como jogar?

1. joga direto no navegador: **https://birenes.github.io/bomberCAT/**
2. ou baixa o `bomberCAT.html` e dá dois cliques (abre no navegador e roda offline).

### Controles
- **1 2 3** : navegar nos menus / escolher dificuldade
- **setas** ou **WASD** : andar
- **espaço** : soltar bomba
- **ESC** : pausar

dica: tem um easter egg se você digitar um certo nome no comecinho :)
